# Specs

The four documents the product is built from, checked in verbatim as the user
supplied them. They are the source of truth for scope and for required states;
they do not outrank a direct instruction in chat.

| File                   | What it settles                                                           |
| ---------------------- | ------------------------------------------------------------------------- |
| `pages-features.md`    | The nine admin pages, what each does, which are AI                        |
| `feature-checklist.md` | **Required states per feature** — a feature is not done until these exist |
| `states-research.md`   | The quality bar, including Built for Shopify budgets                      |
| `brand.md`             | Voice, colour, naming                                                     |

Two things to know before reading them:

- **`brand.md` describes a narrower product** than the other three — a quote →
  counter → accept → reorder tool that "rides Shopify's native B2B and prices on
  draft orders". The other three describe a full wholesale-pricing suite. The
  build follows the three; the divergence is recorded in `DECISIONS.md`.
- **The plan ladder in `brand.md` §7 is superseded.** The user confirmed
  Free · Pro $29 · Growth $59 · Agentic $99 in chat during task 0.3.
